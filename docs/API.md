### Single Prediction

```
POST /predict
```

**Request:**
```json
{
  "features": {
    "AMT_INCOME_TOTAL": 150000,
    "AMT_CREDIT": 500000,
    "AMT_ANNUITY": 25000,
    "AMT_GOODS_PRICE": 450000,
    "DAYS_BIRTH": -12775,
    "DAYS_EMPLOYED": -1825,
    "EXT_SOURCE_1": 0.5,
    "EXT_SOURCE_2": 0.6,
    "EXT_SOURCE_3": 0.4
  }
}
```

**Response:**
```json
{
  "default_probability": 0.156,
  "prediction": 0,
  "risk_level": "LOW",
  "confidence": "HIGH"
}
```

**Risk Levels:**
- `LOW`: probability < 0.2
- `MEDIUM`: 0.2 ≤ probability < 0.5
- `HIGH`: 0.5 ≤ probability < 0.8
- `VERY HIGH`: probability ≥ 0.8

### Batch Prediction

```
POST /predict/batch
```

**Request:**
```json
{
  "batch": [
    {"AMT_INCOME_TOTAL": 150000, "AMT_CREDIT": 500000, ...},
    {"AMT_INCOME_TOTAL": 80000, "AMT_CREDIT": 300000, ...}
  ]
}
```

**Response:**
```json
{
  "predictions": [
    {"default_probability": 0.12, "prediction": 0, "risk_level": "LOW"},
    {"default_probability": 0.45, "prediction": 0, "risk_level": "MEDIUM"}
  ],
  "count": 2,
  "processing_time_ms": 125
}
```

**Limits:** Maximum 100 records per batch

## Required Features

**Core features (highly predictive):**
- `AMT_INCOME_TOTAL` - Annual income
- `AMT_CREDIT` - Credit amount
- `AMT_ANNUITY` - Monthly payment
- `EXT_SOURCE_1`, `EXT_SOURCE_2`, `EXT_SOURCE_3` - External credit scores (0-1)

**Personal features:**
- `DAYS_BIRTH` - Age in days (negative)
- `DAYS_EMPLOYED` - Employment length in days (negative)
- `CNT_CHILDREN` - Number of children
- `CNT_FAM_MEMBERS` - Family size

## Example Usage

### Python
```python
import requests

response = requests.post(
    "http://localhost:8000/predict",
    json={
        "features": {
            "AMT_INCOME_TOTAL": 150000,
            "AMT_CREDIT": 500000,
            "EXT_SOURCE_2": 0.6
        }
    }
)
print(response.json())
```

### cURL
```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"features": {"AMT_CREDIT": 500000, "AMT_INCOME_TOTAL": 150000}}'
```
